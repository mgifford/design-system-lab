Scope and principles

Research, not an official release

This MIT-licensed comparison lab evaluates proposed improvements to published USWDS components. It is independent of GSA, USWDS maintainers, and the Open Government Design System.

What is actually compared?

USWDS 3.14.0 is installed as an exact npm dependency and its distributed styles and JavaScript are copied during the production build. The experimental column uses the same baseline plus an isolated MIT-licensed CSS layer. This pilot does not yet execute OGDS Elements or USWDS Elements; their repositories are listed for future integration and research. A local build without installed USWDS assets is explicitly an offline illustration only.

Testing methodology

Each fixture has a documented expectation and a Playwright test. CI exercises component visibility, interaction, theme controls, page navigation, and a no-JavaScript case. A separate evidence collector captures readable results and Guidepup virtual speech transcripts for each fixture, with source versions, known limitations, and human review left pending. Playwright MCP may be used for exploratory steps, but repeatable assertions belong in checked-in Playwright tests.

Dark mode and user preferences

Dark mode is a demonstrator of the design-system changes needed for consistent presentation. It does not guarantee correct contrasts in every state and does not override an operating system's forced-color palette. The baseline is deliberately kept unchanged. Test forced colors, RTL, reduced motion, and browser zoom independently.

Governance and AI

AI-assisted code and evidence summaries require explicit disclosure, reproducible steps, human review, and attribution where appropriate. A published experiment is a proposed implementation, not an upstream decision. Read ACCESSIBILITY.md reference work for additional guidance.
