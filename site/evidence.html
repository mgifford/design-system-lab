How to interpret this evidence

Playwright tests check defined assertions. A pass is not a WCAG conformance claim. Guidepup uses a virtual screen reader over a DOM snapshot; it does not reproduce actual VoiceOver or NVDA operation. Human review is a separate status, never inferred from automated output.

Review methodology and the repository's ACCESSIBILITY.md before relying on results.

Every report should state what was tested, what failed, and what was not tested.
