New component proposal

User preferences panel

A consistent place to choose appearance, text size, contrast, and motion. It is an alternative to third-party accessibility overlays, not a replacement for accessible design, browser preferences, or assistive technology.

No equivalent preference panel is included in stable USWDS 3.14.0. This is a proposed component, not an upstream feature. Teams currently implement their own controls, storage, reset behavior, and documentation. The absence of a stable baseline is a capability gap, not an accessibility failure.

Try the panel

Changes apply immediately on this device. The preference is stored only in this browser with localStorage; it is not sent anywhere. Reset returns to system defaults.

What each setting does

Preference behavior and scope
SettingBehaviorLimit
AppearanceSets an explicit light or dark theme, or removes the override so prefers-color-scheme applies.The lab’s experiment fixtures support the theme; the stable baseline stays unchanged.
Text sizeScales the root font size to 100%, 112.5%, or 125%.It does not replace browser zoom or a user stylesheet. Test 200% and 400% zoom separately.
ContrastStrengthens borders and focus indicators.It is not a high-contrast mode and does not override forced colors.
MotionReduces non-essential animation and transitions.It does not replace the OS reduced-motion setting for other sites.
ResetDeletes the stored preference and returns to system defaults.The current page updates immediately; other open tabs may need a reload.

Implementation and limitations

The panel uses native radios and selects, a labelled fieldset, a status region, and no custom widget role. Persistence is limited to this origin and may fail in private browsing; the implementation catches storage errors and keeps the current page usable. No personal information is stored.
